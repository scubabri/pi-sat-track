## Using this as a GitHub Wiki

1. Repo **Settings → Features → Wikis** enabled  
2. Create the first page in the GitHub UI (enables the wiki repo), or clone `https://github.com/scubabri/pi-sat-track.wiki.git`  
3. Copy `Home.md` and `_Sidebar.md` into the wiki repo and push  

Until then, read **[Home.md](Home.md)** directly in this `docs/` folder.
